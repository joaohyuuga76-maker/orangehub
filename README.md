# OrangeDesk 🧡

Aplicativo mobile-first para gestão compartilhada de uma loja Shopee: checklist de tarefas, responsáveis, recorrência, vendas e dashboard.

## Estado atual

Este repositório está recebendo o código do MVP. A integração com a Shopee **não está ativa** e requer autorização oficial e credenciais apropriadas.

## Stack

Next.js, TypeScript, Tailwind CSS e Supabase.

## Segurança

Nunca commitar `.env.local`, chaves privadas ou tokens da Shopee. Configure as variáveis de ambiente no provedor de hospedagem.

## Próximas etapas

Concluir importação dos componentes, aplicar o SQL do Supabase, configurar autenticação e publicar na Vercel.
